# Agricart — عام سمجھ کا مکمل مینو میپ (آسان اردو)

یہ فائل **ایک جگہ** بتاتی ہے کہ ایڈمن سائیڈ بار میں کون سے مینو ہیں، ہر مینو میں کتنے سب‌مینو ہیں، اور ہر صفحے کا کام کیا ہے۔  
تکنیکی کوڈ کی تفصیل نہیں — روزمرہ کام کی زبان میں۔

**آخری اپڈیٹ:** نومبر 2026

## 1) ڈیش بورڈ (3)

1. **جائزہ** — لاگ اِن کے بعد عام ہوم / خلاصہ کارڈز۔  
2. **خلاصہ** — اہم اعداد و اعداد کا مختصر منظر۔  
3. **نوٹس** — ذاتی یا دفتر کے نوٹس لکھنے کی جگہ۔

---

## 2) منظوریاں (3)

1. **جائزہ** — منظوریوں کا خلاصہ۔  
2. **عملہ** — جو لوگ ملازمت / عملہ بننے کی درخواست دیں، انہیں منظور یا مسترد کرنا۔  
3. **سپلائرز** — نئے سپلائر کی درخواستیں دیکھنا اور منظور کرنا۔

---

## 3) رابطے (5)

یہاں **لوگ اور کمپنیاں** محفوظ ہوتی ہیں۔

1. **جائزہ** — رابطوں کا خلاصہ۔  
2. **گاہک (Customers)** — دکان کے خریدار۔  
   - لوکل / آف لائن گاہک یہاں سے بنتے ہیں؛ کاؤنٹر سیل میں منتخب ہوتے ہیں۔  
   - آن لائن گاہک ویب رجسٹریشن / چیک آؤٹ سے بھی بن سکتے ہیں، پھر یہاں ریکارڈ نظر آتا ہے۔  
3. **سپلائرز** — جن سے مال خریدا جاتا ہے۔  
4. **کیریئر کمپنیاں** — ٹرانسپورٹ / کوریئر کمپنیاں۔  
5. **میسج ٹیمپلیٹس** — تیار پیغامات (واٹس ایپ / ایس ایم ایس وغیرہ کے سانچے)۔

---

## 4) مصنوعات — Catalog (11)

مال کی فہرست اور اس کی ترتیب۔

1. **جائزہ** — کیٹلاگ کا خلاصہ۔  
2. **مصنوعات** — اصل پروڈکٹس: نام، قیمت، اسٹاک، تصاویر۔  
3. **پروڈکٹ ریویوز** — گاہک کی پروڈکٹ ریویو دیکھنا / سنبھالنا۔  
4. **زمرے (Categories)** — مثلاً بیج، کھاد، آلہ۔  
5. **برانڈز** — کمپنی / برانڈ نام۔  
6. **پیکجز** — پیکج آفرز۔  
7. **اکائیاں (Units)** — کلو، لیٹر، عدد وغیرہ۔  
8. **پیکنگ اکائیاں** — پیکنگ یونٹس۔  
9. **خصوصیات (Attributes)** — سائز، رنگ جیسی اضافی فیلڈز۔  
10. **پروڈکٹ لیبلز** — لیبل پرنٹ۔  
11. **کنٹرول** — کیٹلاگ سے متعلق کنٹرول سیٹنگز۔

---

## 5) خریداری (9)

سپلائر سے مال اندر لانا۔

1. **جائزہ** — خریداری کا خلاصہ۔  
2. **خریداری منصوبہ بندی** — کیا خریدنا ہے اس کی منصوبہ فہرست۔  
3. **خریداری کوٹیشنز** — سپلائر سے ریٹ / کوٹیشن۔  
4. **خریداری (Purchases)** — اصل پرچیز بل، اسٹاک بڑھتا ہے۔  
5. **خریداری ادائیگی سمری** — سپلائر کو کیا ادا ہوا / باقی۔  
6. **خریداری ری آرڈرز** — جو چیزیں ختم ہو رہی ہوں ان کا ری آرڈر۔  
7. **قیمت ٹیگز** — قیمت کے ٹیگ۔  
8. **ریٹ لسٹ** — ریٹ لسٹ دیکھنا / پرنٹ۔  
9. **پرائس اپڈیٹ** — خرید / سیل ریٹ اپڈیٹ۔

## 6) فروخت — Sales (9)

یہاں **دو بڑے راستے** ہیں:

### الف) لوکل / کاؤنٹر سیل
- **سیلز اینڈ پی او ایس** پر گاہک منتخب کرو (یا واک اِن)، پروڈکٹ ڈالو، نقد یا بینک، بل مکمل۔  
- اسٹاک کم ہوتا ہے؛ ریکارڈ سیلز میں رہتا ہے۔

### ب) آن لائن سٹور سیل
1. گاہک ویب سٹور پر آرڈر دیتا ہے → **آن لائن کوٹیشن** بنتی ہے۔  
2. ادائیگی / رسید کی تصدیق۔  
3. **Convert into Invoice** کے بعد آرڈر **آن لائن آرڈرز ان کیو** میں آتا ہے۔  
4. وہاں سے فارورڈ / پیکنگ / شپنگ۔  
5. اگر کوٹیشن کینسل ہو → **کینسلڈ کوٹیشنز** میں محفوظ رہتی ہے (نمبر ڈیلیٹ نہیں ہوتا)۔

### سب‌مینو تفصیل

1. **جائزہ** — فروخت کا خلاصہ اور کارڈز۔  
2. **سیلز اینڈ پی او ایس** — لوکل کاؤنٹر سیل / انوائس۔  
3. **سیل کوٹیشنز** — آف لائن/دستی سیل کوٹیشن (پرنٹ وغیرہ)۔  
4. **آن لائن کوٹیشنز** — ویب چیک آؤٹ کے بعد ادائیگی سے پہلے کی فہرست؛ یہاں تصدیق، ریجیکٹ رسید، یا **Cancel quotation**۔  
5. **کینسلڈ کوٹیشنز** — کینسل شدہ آن لائن کوٹیشنز کا آرکائیو (نمبر، وجہ، کون نے کینسل کیا)۔  
6. **آن لائن آرڈرز ان کیو** — ادا شدہ / انوائس شدہ آرڈرز جو ڈسپیچ قطار میں ہیں۔  
7. **فارورڈڈ** — جو آرڈرز سپلائر یا عملے کو بھیجے جا چکے۔  
8. **سیل ریٹرنز** — واپسی / ریفنڈ۔  
9. **اسٹاف ان باکس** — عملے کے اندرونی پیغامات / فارورڈ نوٹس۔

**فرق یاد رکھو:**  
- **Reject** = صرف گاہک کی **رسید** مسترد (کوٹیشن زندہ رہتی ہے)۔  
- **Cancel quotation** = کوٹیشن ختم؛ **کینسلڈ کوٹیشنز** میں چلی جاتی ہے۔

11. **ریویوز** — گاہک ریویوز۔

## روزمرہ فلو (یاد رکھنے کے لیے)

```
گاہک بنانا ──► رابطے → گاہک
       │
       ├─ لوکل سیل ──► فروخت → سیلز اینڈ پی او ایس
       │
       └─ آن لائن ──► سٹور ویب سائٹ پر آرڈر
                         │
                         ▼
              فروخت → آن لائن کوٹیشنز
                         │
            ┌────────────┼────────────┐
            ▼            ▼            ▼
      رسید Reject   Cancel       ادائیگی OK
      (کوٹیشن زندہ)  (کینسلڈ     Convert Invoice
                     کوٹیشنز)         │
                                      ▼
                         آن لائن آرڈرز ان کیو
                                      │
                                      ▼
                              لاجسٹکس / فارورڈ
```

خریداری کا سادہ فلو:

```
منصوبہ / کوٹیشن ──► خریداری بل ──► اسٹاک بڑھے ──► سپلائر لیجر / ادائیگی سمری
```
