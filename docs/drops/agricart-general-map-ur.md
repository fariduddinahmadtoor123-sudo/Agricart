## حصہ ۳ — سب‌مینو اور اس کا فنکشن

### 1. ڈیش بورڈ
- **جائزہ** — لاگ اِن کے بعد عام ہوم صفحہ۔  
- **خلاصہ** — اہم اعداد کا مختصر منظر۔  
- **نوٹس** — ذاتی / دفتر نوٹس لکھنا۔  

### 2. منظوریاں
- **جائزہ** — منظوریوں کا خلاصہ۔  
- **عملہ** — نئے عملہ کی درخواست منظور / مسترد۔  
- **سپلائرز** — نئے سپلائر کی درخواست منظور / مسترد۔  

### 3. رابطے
- **جائزہ** — رابطوں کا خلاصہ۔  
- **گاہک** — خریدار بنانا / دیکھنا۔ لوکل سیل اور آن لائن دونوں یہیں سے جڑتے ہیں۔  
- **سپلائرز** — جن سے مال خریدا جاتا ہے۔  
- **کیریئر کمپنیاں** — ٹرانسپورٹ کمپنیاں۔  
- **میسج ٹیمپلیٹس** — تیار پیغامات کے سانچے۔  

### 4. مصنوعات
- **جائزہ** — کیٹلاگ خلاصہ۔  
- **مصنوعات** — پروڈکٹ، قیمت، اسٹاک، تصویر۔  
- **پروڈکٹ ریویوز** — گاہک ریویو سنبھالنا۔  
- **زمرے** — پروڈکٹ کیٹیگری۔  
- **برانڈز** — برانڈ نام۔  
- **پیکجز** — پیکج آفر۔  
- **اکائیاں** — کلو، لیٹر، عدد وغیرہ۔  
- **پیکنگ اکائیاں** — پیکنگ یونٹ۔  
- **خصوصیات** — اضافی فیلڈز (سائز وغیرہ)۔  
- **پروڈکٹ لیبلز** — لیبل پرنٹ۔  
- **کنٹرول** — کیٹلاگ کنٹرول سیٹنگ۔  

### 5. خریداری
- **جائزہ** — خریداری خلاصہ۔  
- **خریداری منصوبہ بندی** — کیا خریدنا ہے اس کی فہرست۔  
- **خریداری کوٹیشنز** — سپلائر سے ریٹ۔  
- **خریداری** — پرچیز بل؛ اسٹاک بڑھتا ہے۔  
- **خریداری ادائیگی سمری** — سپلائر کو ادا / باقی۔  
- **خریداری ری آرڈرز** — ختم ہوتے مال کا ری آرڈر۔  
- **قیمت ٹیگز** — قیمت کے ٹیگ۔  
- **ریٹ لسٹ** — ریٹ لسٹ دیکھنا / پرنٹ۔  
- **پرائس اپڈیٹ** — ریٹ اپڈیٹ کرنا۔  

### 6. فروخت
- **جائزہ** — فروخت خلاصہ۔  
- **سیلز اینڈ پی او ایس** — لوکل کاؤنٹر سیل / بل۔  
- **سیل کوٹیشنز** — دستی سیل کوٹیشن۔  
- **آن لائن کوٹیشنز** — ویب آرڈر ادائیگی سے پہلے؛ یہاں تصدیق، رسید Reject، یا Cancel۔  
- **کینسلڈ کوٹیشنز** — کینسل شدہ آن لائن کوٹیشنز (نمبر محفوظ)۔  
- **آن لائن آرڈرز ان کیو** — ادا / انوائس شدہ آرڈر ڈسپیچ کے لیے۔  
- **فارورڈڈ** — جو سپلائر یا عملے کو بھیجے گئے۔  
- **سیل ریٹرنز** — واپسی۔  
- **اسٹاف ان باکس** — عملے کے اندرونی پیغام۔  

**یاد رکھو:** Reject = صرف رسید مسترد۔ Cancel = کوٹیشن ختم → کینسلڈ لسٹ۔  

### 7. اسٹور
- **جائزہ** — سٹور خلاصہ۔  
- **اوپر پٹی** — سائٹ کی سب سے اوپر والی پٹی۔  
- **ٹکر** — چلتی خبر۔  
- **ہیڈر** — لوگو / فون۔  
- **مینیو** — ویب مینو۔  
- **ہیرو سلائیڈر** — ہوم بڑی تصاویر۔  
- **صفحات** — اندرونی صفحات کا مواد۔  
- **فٹر** — نیچے والے لنکس۔  
- **اشیاء** — سٹور آئٹمز کنٹرول۔  
- **ایگری کارٹ ان باکس** — گاہک پیغام / نوٹیفکیشن۔  
- **ریویوز** — پروڈکٹ / گاہک ریویو۔  
- **Brand Reviews** — برانڈ ریویو۔  
- **Testimonials** — تعریفیں۔  
- **بلاگ** — مضامین۔  
- **وزیٹر اینالیٹکس** — وزٹر اعداد۔  
- **SEO** — سرچ سیٹنگ۔  
- **About** — ہمارے بارے میں۔  
- **رجسٹریشن نوٹس** — رجسٹریشن ہدایات۔  

### 8. لاجسٹکس

## مختصر فلو (یادداشت)

لوکل سیل: رابطے → گاہک → فروخت → سیلز اینڈ پی او ایس  

آن لائن سیل: ویب آرڈر → آن لائن کوٹیشنز → (Cancel تو کینسلڈ) یا انوائس → آن لائن آرڈرز ان کیو → لاجسٹکس  

خریداری: منصوبہ / کوٹیشن → خریداری بل → اسٹاک بڑھے → ادائیگی سمری
